# The photographs are not in this repository, and that is deliberate

This sample was built around nine photographs taken from the restaurant's own website.
They belong to the restaurant and to whoever took them. **This repository is MIT
licensed, and an MIT licence on somebody else's photographs would be a false statement
about who may reuse them.** So they are not here.

To run the sample with its images, fetch them into this directory yourself:

```bash
bash samples/schnackertz/assets/traer.sh
```

The page renders without them. It renders badly, which is the point of the lesson written
into `references/02-density-axis.md`: a restaurant page with no food on it is not worth
what it costs, and the first version of this sample was rejected for exactly that.

The same rule applies to anything you build with this skill. Photographs of a business
belong to that business. Use them in a proposal to that business, and settle the licence
before anything goes live.
