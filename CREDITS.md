# Credits

`tails` is an original synthesis, and it takes specific, named ideas from work that came
first. Every one of these was read directly on 2026-09-07 before being adapted.

| From | What was taken |
|---|---|
| **[Nutlope/hallmark](https://github.com/Nutlope/hallmark)** (MIT) | The **diversification stamp** — write the chosen shape into the CSS, and require the next build to differ from it. `tails` extends it from 21 named macrostructures to a five-axis combinatorial space with a three-axis minimum difference. Also the scope contract: no invented copy, no invented brand, visual layer only, existing stylesheet append-only |
| **[pbakaus/impeccable](https://github.com/pbakaus/impeccable)** (Apache-2.0) | **Deterministic detectors that run without a model.** `checks/slop.mjs` exists because of this idea. Also the `PRODUCT.md` / `DESIGN.md` separation between durable business truth and visual system |
| **[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)** (MIT) | The **one-line design read** before any code, and the principle that *the audience picks the aesthetic, not your taste* |
| **[educlopez/ui-craft](https://github.com/educlopez/ui-craft)** (MIT) | The acceptance question: **"would somebody believe a person designed this?"** — and that failing it means starting again, not adjusting |
| **[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)** (MIT) | 74 brand design systems in readable text. The `DESIGN.md` format `tails` recommends per project |
| **[Anthropic's frontend-design skill](https://github.com/anthropics/skills)** | The lineage all of the above start from |
| **[x1xhlol/system-prompts-and-models-of-ai-tools](https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools)** | The leaked system prompts that made it possible to show the slop is *taught*, not inferred |

Measurement subjects, read from the outside with a headless browser and cited by what
they do rather than quoted: garden-eight, shiftbrain, taotajima, mount, rhizomatiks,
monopo, dentsulab, obys.agency, basement.studio, unseen.co, resn.co.nz, locomotive.

Technical teardown: the Codrops write-up of the Trionn build, for the two-layer hero and
the single-ticker pattern.

Named for the tails of a distribution, after the 2024 *Nature* paper on model collapse.
